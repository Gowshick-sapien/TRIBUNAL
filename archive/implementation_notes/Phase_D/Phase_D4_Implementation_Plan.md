# Phase D.4 — Interactive Evidence Graph Visualization Platform (Implementation Plan)

## Objective

Transform the static Evidence Graph generated during Phase C into a fully interactive visual investigation workstation using React Flow (`@xyflow/react`), Dagre DAG layouting, and custom node/edge components.

The platform provides an explainable visual representation of the Tribunal's reasoning process by rendering the persisted graph structure generated by the Evidence Graph Builder in Phase C and stored through the Repository Layer in Phase D.2 via `GET /api/v1/graph/{id}` without introducing client-side calculation or backend logic.

---

## Architectural Position

```text
                     Investigator
                          │
                          ▼
         React Evidence Graph Viewer (D.4)
                          │
                REST API (/api/v1/graph/{id})
                          │
                          ▼
             Investigation Service Layer
                          │
                   Repository Layer
                          │
                 Persisted Graph JSON
```

## Components & Modules Built

### 1. Types & Services
- [types/graph.ts](file:///d:/TRIBUNAL/dashboard/src/types/graph.ts): Data contracts for `GraphNodeData`, `GraphEdgeData`, `EvidenceGraphPayload`, and `GraphFilterOptions`.
- [services/graph_api.ts](file:///d:/TRIBUNAL/dashboard/src/services/graph_api.ts): Service wrapper mapping `GET /api/v1/graph/{id}` to rich graph nodes.

### 2. Custom Node Types (`components/graph/nodes/`)
- [CardNode.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/nodes/CardNode.tsx): Primary Investigation Cards (Financial/Behaviour Expert, hypothesis, confidence meter, severity border glow).
- [TribunalNode.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/nodes/TribunalNode.tsx): Multi-Expert Tribunal Consensus Verdict node.
- [DefenseNode.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/nodes/DefenseNode.tsx): Adversarial Defense Counter-Review node.
- [EvidenceGapNode.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/nodes/EvidenceGapNode.tsx): Missing Evidence / Investigation Gap node.

### 3. Graph Studio Components (`components/graph/`)
- [EvidenceGraph.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/EvidenceGraph.tsx): Main React Flow canvas workspace.
- [GraphToolbar.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/GraphToolbar.tsx): Canvas controls (Zoom in/out, fit screen, reset, winning path toggle, export PNG).
- [GraphLegend.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/GraphLegend.tsx): Visual legend for node categories and edge types.
- [NodeInspector.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/NodeInspector.tsx): Persistent right side-panel for node provenance details.
- [EdgeInspector.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/EdgeInspector.tsx): Persistent right side-panel for edge relationship details.
- [GraphMetrics.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/GraphMetrics.tsx): Topology statistics panel.
- [SearchBar.tsx](file:///d:/TRIBUNAL/dashboard/src/components/graph/SearchBar.tsx): Live search & filter controls.

### 4. Custom Hook & Pages
- [useEvidenceGraph.ts](file:///d:/TRIBUNAL/dashboard/src/hooks/useEvidenceGraph.ts): State hook calculating Dagre DAG layouting and applying search/filter overlays.
- [EvidenceGraphPage.tsx](file:///d:/TRIBUNAL/dashboard/src/pages/EvidenceGraphPage.tsx): Dedicated Fullscreen Evidence Graph Studio reachable via `/graph/:id`.
- [ViewerPage.tsx](file:///d:/TRIBUNAL/dashboard/src/pages/ViewerPage.tsx): Embeds `EvidenceGraph` directly inside Tab 2 ("Evidence & Graph") with an "Open Fullscreen Studio" button.
